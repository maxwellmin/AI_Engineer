## 使用说明

### 如何更新进度

1. **完成一个阶段后**: 更新状态为 ✅，填写完成日期和说明
2. **开始新阶段时**: 更新状态为 🔄
3. **遇到阻塞时**: 更新状态为 🚫，说明阻塞原因

### 在 Plan 模式中使用

每次进入 plan 模式开始新阶段开发时，AI 会：
1. 自动读取此文件了解当前进度
2. 确认依赖关系是否满足
3. 制定该阶段的详细实现计划
4. 完成后更新此文件

### 更新命令示例

```
# 使用 # 前缀快速添加记录
# 阶段 2 基础搭建已完成，创建了 Django 项目结构

# 或在对话中要求更新
请更新 progress.md，标记阶段 2 为已完成
```
